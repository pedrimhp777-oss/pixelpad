# ViGEmClient.dll

`ViGEmClient.dll` (x64) é a biblioteca cliente do projeto
[ViGEmClient](https://github.com/nefarius/ViGEmClient), de Nefarius Software
Solutions, licenciada em **BSD 3-Clause**.

Ela conversa com o driver **ViGEmBus** (instalado separadamente) e é o que cria o
controle Xbox 360 virtual. Redistribuída aqui sem modificações, apenas para que o
PixelPad funcione sem precisar compilar nada.
